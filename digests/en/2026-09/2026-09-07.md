### [Improve display of GUCs that are customarily written in octal.](https://github.com/postgres/postgres/commit/23c07b4604387b98efd25246b185b57be237d7ca)
**Tom Lane**

This commit improves the display of integer-valued GUCs, like Unix file permission masks, that are conventionally shown in octal. It replaces custom `show_hook` functions with a new `GUC_SHOW_IN_OCTAL` flag to ensure consistent octal representation for current, min, max, reset, and boot values in `pg_settings`.

---

### [Reset conflict slot's xmin when a subscription (re)starts retention.](https://github.com/postgres/postgres/commit/6168c65ddcac4494fb292418cc774897791e0667)
**Amit Kapila**

This commit fixes an issue where the `xmin` of a cluster-wide replication slot was not correctly reset when a subscription restarts its retention. This could lead to an assertion failure if a newly created subscription had an older active transaction than the slot's current `xmin`, particularly when using the `retain_dead_tuples` feature for conflict detection.

---

### [Fix duplicate qual clauses in parameterized paths](https://github.com/postgres/postgres/commit/f836b688f8dc627ce97760dec5569aa7c064ffe9)
**Richard Guo**

This commit addresses a bug where duplicate qual clauses could be generated in parameterized paths, particularly when outer-join identity permits join commutation. Previously, `subbuild_joinrel_restrictlist` would select the correct clone for join clauses, but this selection was missing for movable join clauses pushed into parameterized paths, leading to incorrect query planning.
