### ⭐ [Make property graph object descriptions better translatable](https://github.com/postgres/postgres/commit/e0ff7fd9aa2e6f77c38825e71200ced742220d55)
**Peter Eisentraut** — *Discussion: [20260528.121622.1662808269492494574.horikyota.ntt@gmail.com](https://www.postgresql.org/message-id/flat/20260528.121622.1662808269492494574.horikyota.ntt%40gmail.com)*

This commit refactors `getObjectDescription()` to build property graph-related object descriptions as full messages rather than incrementally with `appendStringInfo()`. This change ensures that word order is not fixed to English, allowing for natural translations into languages such as Japanese.

**Why it matters:** Incremental building of object descriptions in property graphs fixed the word order in English, making it extremely difficult to translate them naturally into other languages.

**Technical challenge:** The previous implementation constructed messages incrementally by appending strings, which fixed English word order. Refactoring this required designing unified description formats that can be adapted to different grammatical structures.
