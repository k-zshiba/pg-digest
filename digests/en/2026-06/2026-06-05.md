### ⭐ [refint: Remove plan cache.](https://github.com/postgres/postgres/commit/1fbe2066dcc882321e87fdac43b942b890338f34)
**Author: Nathan Bossart**

This commit removes the per-backend plan cache within the `refint` module. The cache was causing issues such as reusing stale key values in cascade-UPDATE queries and was never properly invalidated.

**Author: Peter Eisentraut**

This commit fixes an issue where `LATERAL` references in `GRAPH_TABLE` queries with multi-label patterns were incorrectly handled. It ensures that `levelsup` for lateral references is correctly adjusted when a pattern results in a `UNION` of multiple path queries.

### [Handle element label and label property objects in object address functions](https://github.com/postgres/postgres/commit/72498a86989e3491228ba09be43eab778a3ac943)
**Author: Peter Eisentraut**

The functions `getObjectTypeDescription()` and `getObjectIdentityParts()` are updated to correctly handle objects from the `pg_propgraph_element_label` and `pg_propgraph_label_property` catalogs. This prevents "unsupported object class" errors when these functions are called for DDL operations on such objects.

### [xml2: Fix stylesheet document leak in xslt_process()](https://github.com/postgres/postgres/commit/9ec568b3eb6a8e8aad9041078e4c7bfedf293ca8)
**Author: Michael Paquier**

A memory leak in the `xml2` extension's `xslt_process()` function has been fixed. The leak occurred when parsing a stylesheet failed, as the allocated `xmlDoc` was not properly freed in the error path.

### [Fix pg_subscription column privileges for subwalrcvtimeout](https://github.com/postgres/postgres/commit/1a5b19e447aa6c2743371dc559f697cf63c7ba82)
**Author: Nisha Moond** — *Discussion: [https://pos](https://pos)*

This commit grants `SELECT` privilege to `PUBLIC` on the `pg_subscription.subwalrcvtimeout` column. This addresses an oversight where non-superusers could not read the column, unlike other publicly readable columns in `pg_subscription`.
