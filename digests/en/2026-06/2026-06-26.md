### ⭐ [Fix out-of-bounds access in autoprewarm worker](https://github.com/postgres/postgres/commit/dac36601fd774a00b3b7390a656a689e2881bcf4)

### [Make crosstabview honor boolean/null display settings](https://github.com/postgres/postgres/commit/4df5fe3833a87f6629eb888ca5a385bcb0b179d9)
**Álvaro Herrera**

This update ensures that psql's `\crosstabview` command now respects the `\pset display_true/false` and `\pset null` settings, providing consistent output for boolean and NULL values with normal query results. Previously, `\crosstabview` would always display "t" or "f" for booleans and an empty string for NULLs, ignoring user preferences.

### [Take into account default_tablespace during MERGE/SPLIT PARTITION(S)](https://github.com/postgres/postgres/commit/cdae794af31b3e9cfc323fc654292d86fa746f77)
**Alexander Korotkov**

This commit corrects an issue where `MERGE/SPLIT PARTITION(S)` operations did not honor the `default_tablespace` GUC setting. Previously, new partitions created through these commands would always land in the database's default tablespace, even if a different `default_tablespace` was configured.
