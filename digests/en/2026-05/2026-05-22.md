### [Improve pg_stat_wal_receiver for CONNECTING status](https://github.com/postgres/postgres/commit/7f469097c72e6f8988024eb9bc1b417bfeb29fd9)
**Michael Paquier**

This commit improves the `pg_stat_wal_receiver` report for the `CONNECTING` status, which previously returned no information while the WAL receiver was attempting to connect to the primary. **Fujii Masao**

This commit adds a missing check to prevent setting `NO INHERIT` on `NOT NULL` constraints for partitioned tables. While creating such constraints with `NO INHERIT` was already rejected, the same check was absent for `ALTER TABLE ... ALTER CONSTRAINT ... NO INHERIT`, which is now rectified.
