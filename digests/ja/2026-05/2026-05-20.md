### ⭐ [Reject degenerate SPLIT PARTITION with DEFAULT partition](https://github.com/postgres/postgres/commit/d8af73010033cb8ad6c941942d6b03d74d7e4f7e)
**Author: Alexander Korotkov**

`ALTER TABLE ... SPLIT PARTITION` でデフォルトパーティションを分割する際に、非デフォルトパーティションが分割対象パーティションと全く同じ境界を保持する退化したケースを拒否するようにしました。これは、単に `SPLIT PARTITION` を介してデフォルトパーティションを追加するコマンドを防ぐためです。

### ⭐ [pg_recvlogical: Add tests for output file permissions](https://github.com/postgres/postgres/commit/d6a72bbe00254139b2a8cbec15eaf576f7b5d358)

コミット `263d1e6dfee` で `pg_recvlogical` が出力ファイル作成時にソースクラスタのファイルパーミッションを尊重するように変更されたことに対し、テストを追加しました。このコミットは、ソースクラスタがグループアクセスなしで初期化された場合はモード `0600` で、グループアクセスが有効な場合はモード `0640` で出力ファイルが作成されることを検証します。

### ⭐ [pg_recvlogical: Honor source cluster file permissions for output files](https://github.com/postgres/postgres/commit/263d1e6dfeec5e573db4f78e6dac4bb17259c482)
**Author: Fujii Masao**

コミット `c37b3d08ca6` は、ソースクラスタでグループアクセスが有効な場合に `pg_recvlogical` の出力ファイルにグループパーミッションを保持しようとしましたが、出力ファイルは固定の `S_IRUSR | S_IWUSR` モードで作成され、グループ読み取りパーミッションが適用されませんでした。このコミットは、ハードコードされたモードではなく `pg_file_create_mode` で出力ファイルを作成することで問題を修正し、`pg_recvlogical` がソースクラスタからグループパーミッションを正しく保持できるようにします。
