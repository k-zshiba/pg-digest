### ⭐ [Allow an aggregate's planner support function to be set via CREATE AGGREGATE.](https://github.com/postgres/postgres/commit/8aa49d34e977affb21f3cdbf17661c9c64753f42)
**Tom Lane**

拡張機能がアグリゲートのプランナーサポート関数を利用できるよう、`CREATE AGGREGATE` コマンドに`SUPPORT` 句を追加しました。これにより、`pg_dump` や `pg_upgrade` もこのプロパティを正しく処理できるようになります。

**なぜ必要か:** 以前の実装ではアグリゲートのプランナーサポート関数を定義するSQLレベルのメカニズムがなく、特に拡張機能からの利用が困難でした。この変更により、拡張機能がパフォーマンス最適化のために独自のプランナーサポート関数を容易に組み込めるようになります。
